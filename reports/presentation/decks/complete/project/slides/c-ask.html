Ask is how people use the data without learning a query language. A question is asked over all documents or only the ones a user has ticked. With Claude on, a router runs a tool-use loop and picks the tools; without Claude, an offline planner maps the question to the same tools. Three tools: run_sql for counts, totals, lists and groupings over the structured data; search_clauses for the clauses closest in meaning, using the vectors; and get_contract for one contract's current terms after amendments. It is safe by construction: SQL runs as a read-only database role, only SELECT is allowed, each query has a five-second timeout and at most 200 rows, and an account limited to one hotel queries views that only contain that hotel. It always shows its work: the answer first, then the SQL it ran, the rows, and the clauses it cited with page and match score.
