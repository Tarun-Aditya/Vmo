THE SOLUTION IN ONE PICTURE

Five layers, from documents to decisions

1 SOURCES

Watched folders, drives, SharePoint, mailbox, ERP and procurement, upload

2 PIPELINE

Read, structure, extract, index, check: every new or changed file

3 DATA

One Postgres database: relational terms and clause vectors together

4 SERVICES

Ask, redline, checklist, obligations, renewals, alerts, spend

5 PEOPLE

Web app for owners, managers, procurement and legal; APIs

Two engines, one path: Claude, or offline rules with no AI calls

Traceable: every value keeps its clause, page and confidence

Configurable: clause library, rules and measures set in Admin

The whole solution in five layers. Sources: wherever contracts live: watched folders, Google Drive, OneDrive and SharePoint, a contracts mailbox, ERP and procurement systems, or an upload. The pipeline reads every new or changed file through the same five steps. The data layer is one Postgres database holding both the relational terms and the clause vectors used for search by meaning. Services run on that data: Ask, redline, the checklist, obligations, renewals, alerts and spend. People use the web app; the same is available through APIs. Three properties run through all of it: two engines on one code path (Claude, or offline rules that make no AI calls, used for demos and as a fallback); every value traceable to its clause, page and confidence; and the business rules configured in Admin rather than hard-coded.
