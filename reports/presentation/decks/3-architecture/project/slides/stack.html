THE STACK

Mainstream, open components; three containers to run

Database

PostgreSQL 16 with pgvector · versioned migrations (Alembic)

Backend

Python, FastAPI, SQLAlchemy, Pydantic · scheduler for runs and alerts

AI

Claude through the Anthropic API or Claude Code · prompts kept as files · offline rules engine

Search

BGE-small embeddings (fastembed, runs locally) · pgvector similarity

Reading

Poppler for PDF, Tesseract OCR for scans, Pandoc and LibreOffice for Word

Frontend

React, TypeScript, Vite, Tailwind, TanStack Query

Run

Docker Compose: database, API, web · one command from a clean clone

Everything is mainstream and open, which keeps cost and lock-in low. Postgres 16 with the pgvector extension is the only data store, with schema changes as versioned migrations. The backend is Python with FastAPI, SQLAlchemy and Pydantic, and a scheduler that runs the pipelines and alerts. AI is Claude, through the Anthropic API or Claude Code; prompts are kept as files so they can be reviewed, and the offline rules engine runs without any model. Search uses the open BGE-small embedding model through fastembed, running locally, with pgvector for similarity. Documents are read with Poppler for PDF, Tesseract for OCR, and Pandoc and LibreOffice for Word. The frontend is React with TypeScript, Vite and Tailwind. It runs as three containers with Docker Compose and starts from a clean clone with one command.
